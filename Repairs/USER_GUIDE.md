# MuseScore Evolution：个人功能使用说明

当前个人版本 **0.42.1**，Kumo branch / Freddd13。本文按功能讲使用方法。第一次使用时先照例子操作；没有列为可用的功能，请不要当成已经完成。

## 从哪里打开

| 想做什么 | 打开位置 |
|---|---|
| 调整音符力度、速度或踏板 | 视图 → 演奏编辑器（力度／速度／踏板）；上方“其他选项”工具栏有同名图标 |
| 直接在谱行旁调演奏数值 | 视图 → 谱行参数带（独立显示）；也可在编辑器勾选“谱行参数带” |
| 查看和弦、级数和音程 | 插件管理器启用 HarmonyAssistant_MS3.qml，然后插件 → Harmony Assistant |
| 检查编配问题 | 启用 ArrangementAssistant_MS3.qml，然后插件 → Arrangement Check |
| 听原曲片段 | 启用 ReferencePlayer_MS3.qml，然后插件 → Reference Player |
| 把演奏 MIDI 的力度和速度用于谱子 | 启用 PerformanceExpression_MS3.qml，然后插件 → Performance Expression |
| 比较不同写法 | 工具 → 分段试写方案；旧版完整副本仍从插件 → Arrangement Variants 打开 |
| 点击估计速度 | 节拍器旁的 TAP，也可在快捷键设置中查找 Tap BPM |
| 导出供视频使用的较短 MIDI 音长 | 文件 → 导出，选择 MIDI，勾选“人性化裁剪：保守踏板模式” |

启用插件：打开“插件 → 插件管理器”，勾选相应文件，关闭管理器后从插件菜单运行。若名单没有它，在偏好设置的插件目录或程序安装目录中确认插件文件。和弦助手的主题控件必须与其它插件一起保留。

本项目右侧面板首次打开时与检视器等并列成标签页。原曲参考可与底部演奏编辑器并列。拖住标题栏可以换位置，或点击面板的“悬浮”。再次打开优先使用你自己摆放的位置。

## 1. 演奏编辑器：先调一个音

**用途。** 调整演奏，不改变音高或谱面时值。需要改写音符，仍在谱面输入。

1. 打开谱子，再打开“演奏编辑器”。在谱面点一个音。
2. 面板上方显示音高和音符，下方显示所选演奏参数。选择“力度”。
3. 找到该音下方力度柱的小圆点，向上拖变强，向下拖变弱。点“选音”可以把视图移到已选音。
4. 松开鼠标保存本次调整。Ctrl+Z 撤销；Esc 取消正在拖动的调整。
5. 打开“试听”后，点选音会发声。播放中选音不额外插入试听音。

亮边框表示选中；播放时的描边表示正在发声；橙色虚框表示尚未保存的调整。播放中改力度会先记住，停止播放、乐谱准备完成后再写入。

**相对与绝对力度。** 假设某个音由力度记号得到80：相对+10%约为88，0%仍为80；绝对88则直接指定88。若以后把力度记号改弱，相对值会跟着改变，绝对值仍为88。整数换算可能使很小的百分比变化暂时听不出。

“MIDI 力度”显示实际数值1–127；“相对%”显示增加／减少百分比。切换显示方式本身不改保存方式。需要转换时用明确的相对／绝对转换按钮，转换后可撤销。

**重叠音。** 在谱面先点要改的音，再直接拖同一时刻的力度柱：优先调整已选音，即使另一个音的圆点更靠近鼠标。开始拖动后不会换目标。远处选中的音不会抢占鼠标所在时刻。仅点按时可轮换重叠音；Alt+单击轮换，Alt 连点不启动播放。右键列出音名、谱表和声部，Ctrl+单击加入多选。拖已有多选柱可以一起调整。

**拖动快慢。** “拖动 1 倍”下拉提供0.25、0.5、1、2、4倍。觉得一拖就变太多时选0.5倍；默认1倍保持原有速度。这个设置不改变滚轮步长和图形缩放。按下鼠标后很小的移动不改值，避免点选时误调。

**缩放。** 参数区左侧“适”匹配选音或当前窗口的数值，“全”恢复完整范围，−／+放大缩小；数字轴滚轮缩放，拖动数字轴移动范围。Ctrl+滚轮缩放时间，Ctrl+Shift+滚轮调纵向，Shift+滚轮横移。

**滚轮。** “滚轮调力度”首次关闭。开启后，把鼠标指向一个音头、力度柱或手柄滚动，每格改1，Shift每格改8。Ctrl+滚轮仍缩放。每段连续滚动合成一次撤销；停转约300毫秒保存，Esc取消尚未保存的部分。

**筛选和颜色。** 点“谱表／声部”打开一张表，每行一个谱表，每列一个声部。取消勾选的音不能修改，可选择淡化作参考或隐藏。“全部”“只看选音所在声部”“只看选中谱表”用于快速选择。音旁手柄、谱行带和编辑器共用筛选；谱面原有选音不会被清掉。跨谱表音按它所属的谱表筛选。

键盘下拉提供“完整键盘”“淡化无关音高”“只显示相关音高”。默认淡化；相关音高来自筛选后的音符。收起其它音高时，音符网格也一起收起，点选仍对应实际音高。键盘用于识音和试听，不修改谱面音高。

“显示…”可选力度、声部、谱表配色。“按声部着色”默认跟随 MuseScore 的声部颜色。在“配色／力度柱宽…”取消“声部颜色跟随 MuseScore”，才使用个人声部色；原有自选色保留。

**比较不同谱表的力度。** 勾选“实际力度＋原力度线”，每个柱显示最终 MIDI 力度，各谱表的虚线连接起音处的原力度。右手mf、左手mp可以看到不同的线；休止期间的虚线只是相邻起音值的连接。取消后回到下拉所选显示，百分比的0%表示不增减，所以共用一条0%线。显示切换不改变音符保存为绝对值还是百分比。悬浮提示同时给出保存值和实际力度。

**用铅笔画力度。** 参数选“力度”，直接点上方“铅笔”后拖过一段力度柱。已有选音时只改选音；没有选音时只改筛选允许的音。“直线”按起点到终点渐变。松开鼠标一次保存，Ctrl+Z一次撤销整段，Esc取消。

**速度和踏板。** 下方参数选择速度时，“选择”工具点按空白处添加速度节点；“铅笔／直线”用于画一段速度。画出的范围结束后恢复原速度。选择踏板时，空白处水平拖动建立踏板区间，拖端点改踩下／抬起位置。踏板吸附可选音符边界、不同细分或自由时刻。请停播后操作。

**找不到或没有变化。** 检查该音是否被筛掉、是否只是淡色参考、是否选了其它参数。播放中请先停播。速度已有可见文字或rit.时需要明确编辑相应节点／曲线，不能直接覆盖。关闭编辑器不删除已保存的演奏调整。

## 2. 谱行带和音旁手柄

**用途。** 不打开大面板也能在乐谱旁调力度。启用独立谱行带，或在编辑器勾选“谱行参数带”“音旁手柄”。

先在谱面选音，再找谱行带中对应的柱；两边同时强调。拖圆点调整，右键可挑选重叠音。音旁手柄只显示选中或鼠标附近音，避免全谱挤满数字。

右键谱行带标题可切换固定在视口底部或跟随当前谱行；选中音决定停播时的谱行，播放时跟随播放所在行。空间足够时放在对应谱行下方；靠近视口边缘时尽量保持在该行附近，实在放不下才使用底部位置。−／+、匹配、全和上下移动控制数值显示，不改变演奏值；数字轴滚轮缩放，拖轴平移。高度在“显示…”中选择，也可拖边缘：跟随谱行时拖下边，固定底部时拖上边。Esc取消正在改变的高度。它与编辑器的纵向缩放分别保存。

标题显示当前音名、谱表、声部和数值。带内的播放线与鼠标线分别表示播放位置和指向位置。筛选及所选参数与编辑器共用。暂停跟随时可手动浏览；再次播放恢复跟随。

**临时查看音旁力度。** 打开过演奏编辑器或独立谱行带后，在谱面按住 Ctrl+Alt+V，显示鼠标附近的力度；再按住Shift显示当前视口所有可编辑音的力度，松开恢复。放大谱面更容易分辨密集的数字。文字输入、输入音符和编辑标记时不接管此按键。“操作设置…”可修改快捷键。

**找最近的音滚动调力度。** 在谱面按住 Alt+Shift 滚动，自动找当前视口内最近的可编辑音，每格改1；本次连续滚动固定这个音，鼠标稍微移开也不换目标。浮标显示当前数值，Esc取消，停转后保存；Ctrl仍用于缩放。普通滚轮模式的Shift每格改8。

## 3. 自动规范输入时值

**用途。** 你输入想持续的时长，软件在需要显示拍点或跨小节时，把它写成延音线连接的几个音。总时长不变。

从“工具”菜单开启“自动规范输入时值”。例如4/4第二拍后半开始的四分音符可能写成八分＋八分，并以延音线相连。跨小节也会继续写完，不截短输入。

**例子一：改掉附点四分后面的八分。** 在4/4第一拍输入附点四分，再输入八分。选后面的八分，把时值改为四分；它会写成八分＋八分，延音跨过第三拍。前面的附点四分保持原样，持续时长和输入光标的位置都不丢失。

**例子二：3-3-2。** 第一拍起输入“附点八分、附点八分、八分”。中间的附点八分在第二拍处分为十六分＋八分，以延音相连。下面是协调符干后的效果，两个延音音符仍按拍点分成两组符杠。

![4/4的3-3-2输入与延音两端符干](docs/images/input-332-036.png)

**跨拍是否连符杠。** “工具 → 允许延音音符跨拍连符杠”首次关闭，保留主要拍点的分组。开启后，同一小节内完整延音连接的短音可以跨拍相连；不会跨小节自动连，也不会覆盖手动指定的分组。这个开关只改变净谱，不改变发声时长。

**协调延音两端的方向。** “工具 → 协调延音两端的自动符干”首次开启。普通单声部、音区相近的音组按这一小段音符的主要方向协调；同一个持续音只算一次。多声部、跨谱表、宽音区、震音、连音组及手动方向继续用原有规则。关闭即可使用原来的自动方向。

这两个设置会重新排版已打开的谱子；播放时先停止，等待乐谱准备完成。它们不写成音符的手动属性；普通MuseScore按自己的规则显示。需要固定保存一种符杠／符干写法时，用原有手动设置，或导出PDF。

附点、符杠和延音分别表达时长、分组和持续。手动指定“不连符杠”的音也会保留设置，自动时值重组不再把它改掉。复杂连音、自定义演奏等保留原设置；特殊记谱需要原样输入时可暂时关闭自动规范开关。

## 4. 琶音、小音符和轻重音

**琶音对拍。** 选中琶音符号，在检视器调整对拍方式和延迟。先用“第一音落拍”或“最后一音落拍”，再改每音间隔；默认入口和详细数值名称见较早版本说明中的“琶音对拍”。可让第一音或最后一音落在写定拍点，其它音依次提前或推后。先用较短延迟试听，松开参数拖动一次保存。已有自定义演奏事件优先。

**快速小音符。** 在“倚音”符号面板选择“快速拍前小音符（无斜线）”，应用到主音。选择小音符或其主音，在检视器“和弦”区设置“播放位置”为拍前，再选“持续时间”：每音毫秒或整组占主音比例。默认每音65毫秒。拍前保留主音原拍点；拍上延后主音；拍后从主音末尾让出时间。数字名称可水平拖动，Shift精调，Esc取消。

**轻重音。** 选中重音记号，在检视器勾选“自定义力度倍率”，输入“力度倍率”。100%不增强；115%轻微增强。也可点“应用轻重音预设（115%）”。取消勾选恢复乐器原效果。拖数值名称可调整，Shift精调，Esc取消。音符的手工绝对力度仍按原生规则优先，不能用重音再覆盖它。

以上均随MSCZ保存，可撤销。未听到变化时确认记号确实附在目标音上，且没有手工演奏事件取代它。各入口和较早版本的完整说明保留在本文末尾。

## 5. 颤音与震音的每一下力度

选中震音斜杠、颤音线或tr记号，在检视器找到“发声力度包络”。“柔和”让重复音比第一下轻；“渐强／渐弱”逐渐改变；“自定义”设置起始、结束及曲率。

例如绝对力度80配90%倍率，实际发声约72。双音震音分别使用两边和弦的音符力度。“交替音减弱”再调整另一边。原样恢复原播放方式，不删除音符的保存力度。

拖名称或输入数字调整，松开一次保存，Esc取消。编辑器可看到实际发声范围，但其中力度柱仍编辑音符保存值。手工演奏事件保留；嗡鸣震音不使用这套逐次音事件。

## 6. 渐慢 rit. 与恢复速度 a tempo

**从符号面板添加。** 展开左侧“速度”，把鼠标放在rit.上可看到“渐慢 rit.（可播放）”。先在谱面拖选一段连续范围，再双击这个格子；或把它拖到谱表小节内，从落下的位置渐慢到该小节末尾。a tempo格子显示“恢复渐变前的速度”：先点选恢复位置，再双击，或直接拖到该位置。两种操作都可一次撤销。

旧速度面板会保留你已有的格子，并补上这两个可播放记号；再次加载不会重复增加。纯文字a tempo格子仍保留，新格子的鼠标说明明确写出播放功能。有速度记号或渐变冲突时会说明原因，不覆盖它们；播放时先停止。

**改变文字和线条。** 选中rit.，检视器的文字线区域分别设置“开始文字”“续行文字”“结束文字”，例如poco rit.。线条区域可控制是否显示线、线条样式、粗细、虚线长度和间隔。需要自定虚线长度和间隔时选择“自定义虚线”；普通虚线使用固定比例。隐藏线条仍会渐慢。手动拖动位置后保留你的设置；与其它文字拥挤时可调整位置和文字字号。

原菜单也保留：选择一段连续乐谱，用“添加 → 文本 → 渐变速度（rit.）”。默认降到原速度的80%，线性渐慢。选择恢复位置，用“添加 → 文本 → 恢复速度（a tempo）”。打开演奏编辑器速度区后可看到曲线。拖曲线两端调范围／速度，拖中间菱形调变化形状。谱面文字与播放相连；改显示文字不等于改实际渐慢。

选中线条，在检视器调整目标速度及曲率。可选目标BPM或相对变化。需要自由画速度时，从曲线右键明确解除播放关联；原文字线仍保留。

a tempo在恢复所在的拍位上方对齐，不再因为位于第一拍而偏到拍号上方；手动偏移保留。a tempo表示回到这次渐变前的速度；Tempo primo回到曲首速度。选中速度文字，在检视器选择恢复方式，也可指定明确BPM。恢复点应在渐变终点或其后，不能放在曲线内部制造冲突。

保存和播放使用同一效果。没有声音变化时检查渐变范围、已有速度文字和冲突提示。文字、曲线和恢复方式都可以撤销。

## 7. Tap：用鼠标估计速度或写速度

点节拍器旁TAP，每次点击代表一拍。至少点击四次才显示正式估计。下拉可选十六分到全音符及附点单位，÷2／×2换算，“重新测量”从头开始。

例如每次敲一个附点四分，测得80，等于四分音符120。面板分别说明点击单位和四分音符BPM。

默认只测量，不改谱。“设为独立节拍器”改变独立节拍器，跟谱播放时会说明不能直接应用。“写入指定位置”先选择小节和起音位置，再新建可见速度标记。

**直接给速度标记 Tap。**

1. 点选谱面上的速度标记，在检视器点“用 Tap 设置速度…”，或在记号右键菜单使用同名入口。
2. 窗口会按这个记号的拍单位开始测量。例如原来是附点四分80，每次点击就代表一个附点四分。也可改为另一种点击单位。
3. 点击窗口内的“Tap · 点击一拍”，或继续使用原工具栏Tap。第二次起出现谱面预览；至少四次后才能保存。窗口同时显示点击单位速度和换算后的四分音符BPM。
4. 点“保存结果”或按回车，一次写入。Esc或“取消”恢复原来的显示。普通数字记号保留原拍单位和说明；只有文字的普通速度会补上数字速度。Ctrl+Z一次撤销本次结果。

预览不会改变谱内速度或试听声音。播放中可以测量和查看，停止播放、乐谱准备完成后才可保存。长时间没有敲击会提示暂停，可保存已有结果；再次开始长停顿后的点击会重新计算。测量期间换谱、删除或修改了目标记号，请关闭窗口后重新选择。

**rit. 的起速／终速。** 选中渐变速度线，在检视器点“用 Tap 设置起速／终速…”，或用线条右键菜单。选择要设置的端点，再敲击；保存会把这一端设为明确BPM，保留另一端和线条文字。与其它速度冲突时显示原因，不会顺便替换其它记号。

**a tempo 与速度关系。** 普通a tempo表示恢复先前速度，速度等式表示比例关系，不能直接当成固定数字。测速窗口保留其含义，提供“保留原记号，写入另一个位置…”；在位置窗口选择另一个起音点，新建固定速度。“恢复到指定BPM”可以直接Tap改变指定值，文字及恢复方式保留。

若新值与旧值相同，不增加多余改动。原工具栏的独立节拍器、倍／半速和写入指定位置功能仍可使用。

![直接测量所选速度标记，先预览再保存](docs/images/tap-035.png)

## 8. 自由圆滑线与左右手折线

**自由圆滑线。** 选中圆滑线，检视器勾选“自由曲线”。添加位置用整条线的时间百分比。双击进入编辑，中间点移动形状，两边手柄控制切线；拖一边仍保持连接处平滑。

箭头微调、Home重置、Delete删除选中的中间点。Esc取消拖动；“重置切线”只调整当前点，“重置节点”清除中间点。关闭自由曲线保留数据，重新开启可恢复。**自动绕开音符。** 勾选“自动避让音符”，同时保持检视器原有“自动布局”开启。先尝试简单弧线；有遮挡时才增加少量临时弯曲。这些临时点不会写成一串手工节点，也不会改变播放。已经手调过的旧曲线默认不开启此功能。

**保留自己调好的点。** 中间点默认锁定。取消“锁定这个点和切线”后，自动避让才可移动它；再勾选锁定，会保留屏幕上当前位置。拖动或修改数值也会自动锁定。添加点时使用当前曲线的位置。两端仍附在原音符上，排版、缩放或保存不会偷偷改动你的节点数据。

**重新自动调整。** “恢复自动形状”清除中间点并开启避让，一次撤销即可恢复。你调整过的两端和原有手柄偏移仍保留；若希望也恢复它们，请使用原生“重置”。关闭“自由曲线”会暂时使用普通曲线，重新开启可恢复保存的数据。

检视器会提示仍有拥挤位置或内容过密。锁定点处有遮挡时，可先解除该点锁定或手动移动；程序不会为了避让把锁定点挪走，也不会无限增高曲线。跨谱行分别调整该行的形状；跨谱表仍采用该行所属谱表的碰撞信息，必要时手调。原有两端手柄改变参考弧线；需固定具体位置时可添加并锁定中间点。普通MuseScore会显示普通曲线，较早个人版可能不保留新解除锁定数据；这些形状请用当前版保存。

![自由圆滑线的自动避让和锁定设置](docs/images/slur-038.png)

**左右手折线。** 在“指法”符号面板选“左手弹（可伸缩）／右手弹（可伸缩）”。选音后添加会附在该音；拖到和弦可附在和弦。标记表示用哪只手，不会把音移动到另一谱表。

**第一次添加。** “指法”面板现在有左手开始、右手开始、左手结束、右手结束四种格子，缩小图例以便辨认。选中具体音后添加：右手标记先放在这个音上方，左手先放在下方；若附在整个和弦，分别参考最高音／最低音。自动布局会在附近尝试避开音头、变音记号和符干。特别密的写法仍可手调，不保证每种排列都能找到空位。

**调形状与位置。** 检视器改横／竖长度、粗细、是否显示LH/RH及方向。双击后拖端点改形状，拖整体改位置，Esc取消。调整过形状或整体位置后保留当前放置，不让再次排版把折线挪回去。重新开启“自动布局”可以重新寻找放置位置；关闭自动布局后仍给出靠近所指音的初始位置。线附近可以点击选中，整块空白区域不会挡住音符。

**保存常用形状。** 只选一个标记，调好长度和线宽，再点“保存为以后添加的形状”。四种标记分别保存；新建默认指法面板时使用它，已有格子保留自己的设置。想在当前标记上采用保存的形状，点“使用保存的默认形状”。播放时未保存的调整需先停播。此按钮改当前标记，可一次撤销；保存个人默认设置不改变谱子。

开始和结束成对时，编配检查读取这段分手信息；只有一个标记时只解释它所指的音或和弦，不影响后面整段。标在和弦里的单个音上，也不会把整个和弦都当成同一只手。范围内有多个声部而不能确定所指线条时会要求确认。折线是否开启、是否显示LH/RH都不改变左／右手含义。

关闭可伸缩模式恢复原字形。当前版MSCX／MSCZ会保存形状与手动放置；较早个人版及普通MuseScore可能不保留这些外观扩展。新默认位置和自动避让只作用于本项目的可伸缩分手标记。

![左右手折线的形状和默认设置](docs/images/hand-039.png)

## 9. 和弦助手

启用插件后，先选调性或确认自动建议，再打开自动识别。谱面选音显示当前内容；播放时查看当前和弦，踏板和延音也参与解释。“踏板内单个／多个和弦”决定一个踏板区间是否允许继续变化。

设置中分别开启音符临时着色、音程文字、谱面和弦、级数，选择仅当前或全谱。颜色只是辅助，原来的选中和播放强调优先。关闭相关开关会清除临时显示，不把它保存成音符原色。

**放在顶部看摘要。** 拖住和弦面板标题放到窗口顶部，摘要只占一行。点“靠左／居中／靠右／自定位置”按钮选择位置；自定位置可用滑条调整。点“详情”同时打开右侧完整面板；点“更多”可打开记号列表或悬浮面板。顶部菜单在独立小窗展开，不受摘要栏高度限制。摘要仍可选择实时音或所属和弦。

**谱面记号和遮挡。** 设置 → 外观中开启“谱面和弦”，选择和弦、级数或两者，再改左右／上下排列、字号和颜色。默认记号画在其它谱面内容上方；两个和弦互相挤到时上下排列，横向仍对齐各自开始的音符，不因找不到空位而省略。

“避让其它谱面内容”首次关闭。开启后尽量找空位，实在放不下仍显示；“遮罩”只控制记号背后的浅色底，两个开关分别生效。页面上方特别密集时也可能排到较低的位置，可关闭避让或调整字号。默认“优先已有和弦记号”会省去与原谱已有和弦相同的临时标记；要逐个查看助手的分析，可关闭这个选项。

点选和播放都强调当前固定位置的记号，双击进入详情。临时记号不会进入打印或PDF，退出插件即清除。

![相邻和弦上下排列，当前和弦高亮](docs/images/chord-034.png)

识别结果不一定是唯一解释。可以指定某段的和弦、低音和范围，添加或删除识别位置，再保存分析文件。导出／导入分析保存音乐解释，不是导出MIDI。选择颜色可直接打开选色器。

**转位与延续低音。** `C/E`表示C和弦、E作低音，详情写“第一转位”；`C/G`是第二转位，`C7/B♭`是第三转位。延伸音或外音在低音时不会冒称普通三／七和弦转位。没有可确定低音时写“低音未确定”。旧低音还在延续、新伴奏已经进入时，会分别说明当前听到的低音和新伴奏低音；例如显示G/C并说明新伴奏低音G，而不是偷偷删去仍在发声的C。

**小调级数。** 设置 → 识别与调性 → “级数参照”：选“当前调式”，A小调的C和弦写III；选“同名大调”，写♭III。默认保留同名大调方式。当前小调的升高第七级用♯VII表示。这个选项改变级数写法，不改音高，也不自动确认主音。

**自动结果与备选。** 新低音和新的伴奏音优先参与判断，踏板残音降低影响；短的级进经过音／邻音不轻易把伴奏改成另一种和弦。相邻位置只能帮助区分接近的解释，不能把不匹配的音强行解释成一个名称。详情若有“也可能是”，请结合旋律和低音选择；两个音或只有新的单音仍可能无法确定。

人工指定的根音拼写保留。导入分析中的和弦文字、级数和N.C.标记也保留，包括休止位置；级数参照不会擅自重写这些导入文字。切换“踏板内单个／多个和弦”后重新分析；跨小节延音没有新起音时，不重复增加相同和弦。

结果不对时先核对调性、低音、踏板模式和解释范围。延长旋律不一定代表和弦没变；人工确认的内容优先。退出插件、换谱或关闭显示会清除其临时内容。

## 10. 编配检查

**先检查四小节。** 在谱面选一段钢琴谱，运行“Arrangement Check”，点“分析”。无选区时检查当前小节，面板写明范围。选择调性钢琴／流行、严格对位或爵士。问题分和声、对位、可弹性；点一项读依据，再点“定位”去看相关音。“忽略此处”只忽略这项提醒，不改音。

**先确认声部和手。** “声部／分手”可改旋律、低音、内声部和左右手，也可选音后校正范围。分手来自用户、符号或自动建议，会写明来源；上／下谱表不等于固定右／左手。开始／结束记号成对时读取范围，未成对时只解释所指音。多声部范围不能确定是哪条线时提示确认。多个钢琴部分分别计算，不把所有音拼进同一双手；非钢琴音不参加钢琴按键计算。

**怎样看可弹性提示。** 例如全音符C2仍在保持，下一拍左手要弹C4/E4/G4：严格保持会占4键、跨度31半音。若同一踏板能保持C2发声，提示先松开C2，之后只需3键、跨度7半音。它只说明这一项限制怎样减少，不能代替实际弹奏。

“设置”分别调整左右手的舒适跨度、最大跨度、两端白键最大跨度。初值是大九度14半音、小十度15半音；两端白键允许大十度16半音。内部有相邻黑白键的大跨度仍会提示检查手型。相同音高的多个声部只算一个琴键。已有简单1–5指法会检查是否要求同一手指同时保持两个不同键；复杂指法文字不强行解释。

“最短按键参考（ms）”默认120，只用于检查建议，可按需要修改；它不是钢琴的生理下限，也不改谱面时值。导出MIDI的最短音长在导出页单独设置。转场同时写出必要移动距离与起音间隔；琶音、换手和极快片段需要结合实际演奏确认。新起音本身过宽或按键过多时，缩短旧音也不能解决，会明确说明。

**和声与对位。** 踏板踩下前已经按住的音也会在抬踏板前继续参与发声判断；声音还在，不等于手指还要一直按着。和声疑点先考虑经过、邻音和挂留，扩展音不自动判错。对位按确认的连续声部检查，并列出前后音；仅校正左右手不会把八度加倍当成独立旋律。爵士和流行中的有意交叉或平行，可按风格关闭提醒。

“局部和弦”指定这段解释；“导入和声”读取和弦助手分析文件。主音未确认时不报确定的导音解决错误。检查不会自动改配音，也不生成完整指法。

播放中显示已完成的结果；停播后再更新，隐藏面板时暂停分析。角色、分手、局部解释和忽略仅用于当前谱会话，通用设置会记忆。

## 11. 原曲参考：从一段原曲到多条音频

**第一次先循环听四秒。** 运行“Reference Player”，点“打开”，选本地WAV、MP3或FLAC。点“播放原曲”，到起点点“片段开始”，到终点点“片段结束”。也可以在波形上拖出范围，或输入开始／结束的毫秒数。打开“循环”反复听；“淡入”减轻边界突变。速度75表示75%，慢放保持音高，可选50–150%。

**添加人声和伴奏。** 点“添加音轨”再选文件。上方音轨框选择当前查看的文件，每条音轨分别保存片段、速度、音量和关联。“参与”表示这条音轨加入合奏，“静音”暂不听它，“独听”只听勾选独听的音轨。先停止整组播放，再调整这些设置或音量；选择另一条音轨也会先停止整组。

“播放原曲”只听当前文件；“项目 → 只播放全部参与音轨”让各音轨从各自的片段开头一起播放，不需要乐谱。短音轨先结束，整组到最长片段结束。整组循环在声音后台准备，循环至少选0.2秒；更短的片段使用原有单曲播放器。

**建立对应。** 在谱面选第9–12小节，在当前音轨选00:35–00:43，点“关联选区”。列表出现这段对应。点列表项显示音频片段；“跳到乐谱”选中谱段，“播放选中片段”只听音频，“谱位→原曲”找到当前谱位对应的音频位置。

同一段原曲可以对应第9–12小节，也可以再对应第25–28小节；源音频片段可以重叠。人声和伴奏可以各自对应第9–12小节。“编辑关联”中选择播放第几遍，以及“这条关联参加联合播放”。同一音轨在同一谱位有几种写法时只启用其中一条；需要同时叠加的材料放在不同音轨，软件不会悄悄重复播放重叠关联。

“锚点”记录当前谱位和当前音频位置这一对对应。内部对应点须依次向前；跳段另建片段。点“编辑关联”可以移除某个对应点、改名称、反复次数或移除关联；这些操作不会删掉音频文件。

**联合播放。** 选一条关联，然后选播放方式，点“联合播放”：

| 方式 | 听到什么 |
|---|---|
| 开头对齐，各自播放；默认 | 乐谱和原曲在关联起点对齐，此后各自保持速度，可能逐渐错开 |
| 音频跟随乐谱 | 音频按照谱内速度和内部对应点保调伸缩 |
| 乐谱跟随选中音频 | 选中的原曲决定这一段的快慢，乐谱和其它音轨跟随；临时速度不写入谱子 |

总音量只调整参加联合／整组播放的音频，不改乐谱音量。需要的变速超出50–150%时会说明，请调整片段或内部对应点。跨反复跳转的关联请拆成几段。播放可能先包含前一小节、进入本段的延音或踏板；音频到真正关联起点才开始。

乐谱播放时按空格停止，参加联合播放的音轨一起停；未开始联动时，空格仍只控制乐谱。工具菜单另有“播放／停止选定原曲片段”和“联合播放／停止”，可在偏好设置的快捷键页面指定按键。联合循环会释放音符、踏板并重新准备下一次，当前不保证两次之间无间隔；单曲和只播音轨的循环保留连续音频输出。

**进入演奏编辑器。** 点编辑器的“音轨／演奏对应”。音频行与上方音符共用时间尺，滚轮上下浏览音轨；片段填色、名称和波形显示对应的谱位。参与、静音、独听和详细关联仍在原曲参考面板设置。“更多”使用同一组原曲播放菜单操作。关闭这一区域就停止波形读取。

**保存和恢复。** “项目 → 保存工作区”选择JSON文件。音轨、关联、对应点、书签和当前查看位置保存在里面；音频默认引用原文件，不复制整首录音。旧版只含一条音频的工作区也能打开。文件移动后选择相应音轨，再用“重新定位音频”；文件或谱段变化时先核对，再确认关联。关闭插件会停止本次播放，切换标签页可继续听，项目菜单也可选择隐藏时暂停。

没有声音时检查音轨是否参与、静音／独听、音量、输出设备和加载状态。音频准备跟不上时会停止并说明，避免播放位置越跑越偏。缺少媒体扩展只影响此工具。频谱和实时录音尚未加入。

## 12. 演奏表达：先确认对应，再采用力度

![对应连线、选音与确认操作](docs/images/expression-032.png)

准备一份谱和一次演奏的MIDI文件。可按谱弹奏但允许错漏音；也可用任意音高只敲节奏和力度。

1. 在谱面选目标小节，运行“Performance Expression”，点“导入 MIDI”。
2. 选择“按谱演奏”或“音序敲击”，选择旋律、voice或相应声部。必要时限制演奏起止秒和反复次数。
3. 点“自动对齐”。列表显示谱面音与演奏时间，分别统计待确认、漏弹和多弹。
4. 点一项，再点“定位对应音”。检查它确实是这次弹的音；“确认对应”只固定这一对关系，不改乐谱。
5. 错配用“校正…”重新连接；跳段、重复节奏可设锚点。未确认的内容不直接用于写谱。
6. 分别打开力度或Rubato，设置采用强度，点“生成拟采用结果”。默认强度50%，先小幅试听。
7. “差异／应用”查看改哪些音、哪些保留及原因。先“试听原版”，再“试听拟采用结果”。首次会要求保存项目位置，试听用的乐谱放在旁边。
8. “停止试听”“返回原谱”结束比较。满意后在差异窗应用；一次Ctrl+Z可以撤销本次写入。

**在编辑器里查看和校正。** 打开演奏编辑器的“音轨／演奏对应”。上排是谱面起音，下排是演奏起音；演奏时间按首尾对应缩放到这一段的时间尺，连线才表示两音确实对应。`?`是漏弹，`+`是多弹。点击一边会强调另一边，并选中谱面上的对应音；不会因此改变播放位置。

先点一个谱面音，再点一个演奏音，点“连接”重新指定对应；“确认”只确认关系。“更多 → 固定对齐点”固定这处位置，“解除对应”去掉这对音的连接。下方反馈写明操作结果。力度细框是原值，实心是拟采用值，标明实测或推算；下拉切到速度对比，虚线为原速度，实线为拟采用速度。

**带原曲比较。** 先在原曲参考中选择关联和播放方式，再勾选演奏表达的“试听时播放参考音频”。原版和拟采用结果使用同样的谱段、音轨和对应；跟随乐谱时，候选Rubato也会带动音频。停止后“返回原谱”，再决定是否应用。分谱试听仍打开对应分谱，不把它的声部编号拿去修改总谱的其它音。

**力度。** 原始MIDI力度保留。设备中心和斜率用于校准键盘响应；不熟悉时保持默认。伴奏推算须明确开启，它不是实际弹出的伴奏力度。已有手工力度、演奏事件等默认保留；查看保留项后才能明确解除保护。

**Rubato。** 用演奏的快慢处理原有节奏，不重新写音符时值。默认保留这一段总时长和两端速度；可选择采用演奏时长。速度对同一时刻全部声部生效。已有速度文字和曲线受保护，无法满足要求时会说明。

**保存。** 项目保存原始MIDI副本、人工对应和设置。音符或方案变了，须重新读取后再采用旧结果。试听副本不改变原谱路径、未保存状态或撤销记录。没有声音设备时仍可查看副本，但会明确说不能试听。

## 13. 分段试写方案：在一个文件中尝试不同写法

**用途。** 第9–12小节的左手可以有A、B两种写法，第25–28小节的旋律也可以有自己的几种写法。切换左手不会替换右手，也不会替换整首谱。全部写法保存在一个MSCZ文件中；不需要为每一种组合保存一份全谱。

**第一次试写。**

1. 在总谱中选第9–12小节，打开“工具 → 分段试写方案”。旧插件的“内置分段方案”也能打开同一面板。
2. 点“建立组”。填写名称，核对开始和结束小节。在谱表表格中勾选要尝试的声部：每行一个谱表，1–4是MuseScore的四个声部。只想改左手，就只勾选相应谱表和声部。点确定。
3. 列表出现这组方案和“原写法”。悬停组名或范围，可以查看所含谱表、声部。
4. 点“复制写法”，输入“B · 分解和弦”等名称。软件保存原写法，打开新写法；现在直接在谱面改音符、节奏、音旁标记或演奏数值。
5. 点列表中的“原写法”，再点“切换写法”，或双击它。所选小节和声部回到原写法。再切到B，你刚才的编辑仍在。当前所用写法标有“当前”。
6. “同处试听”播放当前组合，并包含必要的进入前文。停止使用原来的播放按钮或空格。没有声音设备时会显示原因，仍可以切换和查看。
7. Ctrl+S保存为MSCZ。以后用本分支打开，恢复上次编辑的组合和全部写法。Ctrl+Z可以撤销编辑、复制、改名、范围扩大和切换；一次切换一次撤销。

可以再为另一段或另一声部建立一组。相同时间的右手与左手能各自切换；同一批音符不能同时属于两组。速度、踏板、调号、谱表文字、和弦文字及力度记号共同使用；单个音的力度、手工演奏事件和附着标记随写法保存。

**范围与连线。** 第一版使用完整小节，各种写法的总拍数、拍号和谱表结构相同。连音组、双音震音、符杠、延音线、圆滑线及歌词延续不能被范围截断；跨谱表记谱须包含相关声部。不能切换时会说明原因。

选中组后点“扩大范围”，选择更早的开始小节或更晚的结束小节。新加入的内容复制给每一种写法，当前谱面不变。需要跨段延音或圆滑线时，先扩大，再添加连接。如果已加了跨界连接，先撤销该连接，扩大后重新添加；软件不会为切换直接删掉它。扩大后不能占用另一组已经使用的声部。改变已有方案段的拍号、总长度或谱表结构会使它暂时不能切换或保存全部写法；撤销这一变化，或导出当前组合的普通版副本。

**主方案、打印和普通版。**

- 每组选择一种写法，点“设为主方案”。普通MuseScore打开这个MSCZ时，会看到各组主方案组成的完整乐谱。
- “显示主方案组合”把屏幕切到这份组合。打印、PDF、MIDI和常规导出使用当前屏幕所示组合；需要另一组合时先切换，再导出。
- “普通版副本”可选“当前屏幕组合”或“普通版主方案组合”，另存为一份不含其它写法的MSCZ。它不改变当前文件的位置，也不覆盖当前打开的谱。
- 含全部方案的乐谱请保存为MSCZ，不能直接另存为MSCX。普通版打开后重新保存，可能丢掉其它写法；向别人发送或用普通版继续编辑时，先导出普通版副本。

**旧项目怎样继续用。** 原来的“Arrangement Variants”仍保留完整谱副本、JSON列表、差异检查及试听。可以直接继续使用。要迁入新功能，先建立接收这些小节和声部的组，点“导入旧写法”，选旧JSON或单独MSCZ／MSCX；JSON中有多组时再选择其中一组。只导入本组范围，段外改动和共同设置不替换。旧谱的拍号、长度和谱表不一致，或文件缺失／已改变时会说明，旧文件不会删除。导入后仍要选择写法并切换，才会显示它。

面板首次与右侧检视器等并列；支持换位置和悬浮。分谱跟随总谱内容；建立或切换方案时先回到总谱。

## 14. MIDI裁剪：先检查转场，再导出

**用途。** 谱面为了分声部写了长音，做瀑布流视频时可能看起来一直按着。此功能只改导出副本的松手时刻，谱面时值、音高、起音、力度和踏板不变。

1. 文件 → 导出，选择MIDI，勾选“人性化裁剪：保守踏板模式”。首次默认关闭。
2. 点“裁剪设置…”，选择小节、声部和旋律保护；“设置左右手的个人跨度…”分别设置双手条件。
3. 点“查看对比…”。优先查看“为下一次演奏提前松开旧音”的行，看原先与松手后的按键数、跨度，再看自然松手变化。
4. 点音条或列表选音；悬停查看完整原因和分手来源。选“排除／恢复这个音”可以保留它，再点“重新计算”。
5. 确认后“返回导出”。勾选“同时导出未裁剪版本”会另存名称-original.mid，方便在惯用播放器比较。

**先处理占手。** 例如左手C2全音符会妨碍下一次C4/E4/G4，只有提前松开后仍由同一受支持踏板保持声音，才生成松手方案。优先保留受保护音，不为了减少长度而突破最短音长。新起音自身过宽、指法或分手不清楚、旧音受保护时会说明仍有问题；不能把裁剪当成完整指法求解。

“为下一次按键提前松手”默认60ms，设置转场前留出的时间。这是操作预设，不保证每种跳跃都能完成。跨度默认与编配检查相同，可分别改；两个工具的个人参数独立保存。导出对比读取实际展开后的MIDI，包括反复、暂停和音符演奏调整。

**其余音的自然变化。** 无冲突时，初始目标为原长度85%、同一声部下次起音间隔90%，最短120ms，可调。±2%随机变化主要由同起音、同一只手的一组音共同决定，各音只保留很小的差别；设为0关闭。随机种子和输入相同时，重复导出相同。它不会反向延长音符。

细轮廓是原长度，实心条是新长度，下方单独显示踏板。横轴和播放位置按实际秒数；变速段也按真实时长比较。“选择谱表声部…”只用于当前谱的本次导出，通用小节／声部设置会记忆。所谓“最高起音线”只是旋律候选，不一定是你的真正旋律，明确声部保护更可靠。

没有踏板、跨抬踏板、半踏板或其它不能判断的控制、手调演奏事件、关系不清楚的同音重触都保留。转场位于延音链内部且分手改变时也保留，需人工检查。对比与最终文件使用同一处理器和参数；先用代表性片段检查听感。本机测试声源的例子处理前后相同，不代表其它声源一定相同。

## 15. 字体、保存及遇到问题

Kumo Piano和Kumo Engrave属于个人字体试验，改变字体可能改变间距和避让；它们不是分析算法。普通文字与音乐符号字体分别设置。需要与其他人交换时先用常规字体和普通版副本检查。

个人演奏、自由线条及分手形状用本分支MSCZ保存。原版或MusicXML不一定保留这些个人扩展；原有标准记谱应能正常显示。没有新增功能使用时，仍按原MuseScore方式输入、选择、播放、打印。

遇到问题请先记录：软件“帮助 → 关于”里的版本、操作入口、所选谱段和具体操作。按钮灰色通常是没有材料、结果过期或正在播放；状态栏会说明。无法打开项目先检查文件是否移动。未保存的拖动用Esc取消，已保存的改动用Ctrl+Z撤销。
