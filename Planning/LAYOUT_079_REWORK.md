# 工作视图与区域尺寸复查

## 用户操作

1. 在编曲视图打开演奏编辑器，调整整个编辑器高度，再拖分隔条改变卷帘与力度区比例。
2. 切到扒谱，再回到演奏编辑；确认刚才的比例。
3. 切到DAW、雕版，再回编曲；确认编辑器高度、内部比例和原先打开的工具。
4. 缩小、放大主窗口，关闭重开编辑器，确认区域可见、能拖、能继续编辑。
5. 第一次进入雕版时，乐谱获得主要空间；可从视图菜单重新打开需要的编辑器与工具栏。再次进入时恢复个人摆放。

## 代码中已确认的处理

- EditorAreas管理每个工作视图的区域尺寸；频谱与写节奏另有整条分隔条恢复逻辑。
- 工作视图先恢复区域，再恢复主窗口，最后再调整区域；需要用保存过的布局验证前后次序。
- 初次进入雕版没有单独安排显示区域，当前可能继承DAW中打开的编辑器。

先用实际Qt鼠标调整尺寸并保留修改前结果。修复围绕布局保存与恢复，保留个人设置和原有编辑操作。

## 修改前的实际结果

日志：P2/out/usability-079-before-pluginhost.txt。

- 真实鼠标将卷帘／力度区比例调到0.405。切换扒谱再回演奏编辑，比例仍为0.405。
- 编曲→DAW→雕版→编曲连续三次，编辑器高度始终550，比例仍为0.405。这组新建布局的操作已正常，应保留。
- 首次进入雕版仍显示演奏编辑器，检查失败。该问题已复现。
- 两项操作加初始化／结束共3项通过、1项失败。当前只增加检查，产品源码及已发布0.78保持原状。

下一步：复查带旧modeLayout和新areaHeights的混合设置、写节奏后返回的页签可见性、首次打开及关闭重开；再根据结果修改。多个恢复入口已由代码确认，但尚未证明它们造成新建布局的尺寸变化。

## 本批修复与复查

- 写节奏保留工具页标签和区域菜单，取消半窗高度调整；返回其它页可继续操作。
- 演奏表达保留已调大的编辑器，并给导入、录制、试听、采用留下可见高度。
- 恢复和显示后按当前宽度合并检查内容高度，复制的已有布局首次打开可完整显示；普通缩放保留大于所需高度的设置。

- 首次雕版收起编辑器及输入工具栏；保存过的布局继续恢复。
