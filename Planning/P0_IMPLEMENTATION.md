# 已批准 P0 实施记录

2026-10-10，用户明确批准《P0 详细计划：编配检查、Tap BPM 与 MIDI 导出裁剪》。该批准只覆盖下列 P0，不授权其余未来功能。

| 已选功能 | 实现路线 | 定位 |
| --- | --- | --- |
| Tap BPM | 独立原生估算器，菜单 QAction 接运输工具栏 | 软件 personal-v0.23.0 |
| MIDI 保守裁剪与对比 | 原生导出显式选项，值事件副本处理器，轻量可取消卷帘 | 软件 personal-v0.24.0 |
| 编配检查 | 独立插件；薄原生完整分页与隔离 JS 任务桥 | 软件 personal-v0.25.0；ArrangementAssistant 1.0.0 |

MIDI 本轮路线取代原独立视频后处理工具的 P0 设想。保留传统规则、自动角色建议＋快速校正、停播延迟局部刷新、保守踏板策略、视觉对比及前后文件。舒适大九度、最大小十度、白键端点大十度均可配置。

验收证据和实际限制见 [P0 README](../P0/README.md)、[编配检查说明](../ArrangementAssistant/README.md) 及软件累计用户说明。原曲播放器、多方案工作区、演奏捕获、AI、完整指法／自动改配和动态乐谱仍待逐项选择。

发布状态由最终软件标签和 git 历史核实，不以本文件授权后续阶段。

本轮发布收尾补充 personal-v0.25.1：旧工作区 TAP 一次性迁移；最终应用版本 0.25.1。后续性能任务继承此基线，P0 不继续递增本体版本。
