## 建议采用的路线

| 需求 | 首选实现 | 需要原生的部分 | 判断 |
| --- | --- | --- | --- |
| 对位、和声疑点、排列、可弹性 | 独立分析插件；复杂计算可用本地辅助进程 | 仅在完整数据读取或受保护批量改谱确有缺口时补通用接口 | 第一版只读、给证据与候选；不把非和弦音直接判成错误 |
| 视频 MIDI 后处理 | 独立离线工具，插件可提供导出入口 | 起步不需要；后续便利入口再评估 | 优先分开“音频演奏数据”和“视频显示数据”，原谱不变 |
| 多种编配方案切换 | 插件管理方案；最终体验采用少量宿主配合 | 安全克隆、独立副本生命周期、范围试听与切换 | 可行，但不把分支塞进音符/小节核心模型；先验证副本隔离 |
| Tap BPM | 小型原生模块 | 菜单 QAction 与现有节拍器旁工具栏接线 | 独立、低耦合、可优先做；默认只估算/设置独立节拍器 |
| MIDI 节奏、rubato、力度录入 | 先离线 MIDI + 传统对齐；后插件与宿主配合 | 实时输入的准确时间戳、设备所有权、录入模式与原生写回 | 先固定音高/已有节奏，后扩展自由节奏；三种意图分开 |
| 原曲播放器、片段关联 | 先独立播放与手动定位；插件原型验证部署 | 深度联动时提供媒体宿主、异步分析和运输控制桥 | 基础播放器先做；频谱和精确同步后做，不重写合成器 |
| 动态乐谱视频 | 仅记入远期待办 | 届时评估离线谱面渲染与时间映射 | 本轮不展开实现 |

## 建议先后顺序

这不是已批准的开发队列。P0/P1 内可按你最常用的工作流调整。

1. **P0，短闭环：** Tap BPM；选区只读和声/对位疑点与基础跨度提示；视频 MIDI 后处理小样。每项可以独立选择，不必先建设大型平台。
2. **P1，减少日常切换：** 基础参考播放器；演奏 MIDI 离线对齐并预览力度/rubato；多方案副本隔离验证。
3. **P2，深入编辑：** 指法与配音候选；方案 A/B 工作区及局部应用；带时间戳的实时 MIDI 捕获；频谱与谱段对应。
4. **P3，远期：** 动态乐谱视频、原曲音频和声分析、任意重复/自由节奏跟随、AI provider。不中断前面已独立交付的功能。

## 评审时最值得先定的事项

| 事项 | 建议默认值 | 后续可选 |
| --- | --- | --- |
| 音乐风格 | 调性钢琴/流行编配，提醒而不禁止色彩音 | 严格对位、爵士/扩展和声、自定义规则 |
| 受保护对象 | 旋律、用户指定低音、手工确定的和弦 | 允许建议替代和声/改旋律 |
| 可弹性 | 舒适跨度和最大跨度分别配置；不以谱表直接分手 | 明确左右手、指法、滚奏/换手许可 |
| 视频输出 | 原音频 + 独立视频 MIDI，固定随机种子 | 单 MIDI 同时驱动声音和画面，需试听核验 |
| 多方案第一阶段 | 停播切换；同长度、同拍号的小节范围；副本隔离 | 跨长度方案、边播边切、复杂反复 |
| 演奏输入第一阶段 | 已知谱/已知音高，先导入 MIDI 文件；分别处理力度与 rubato | 实时捕获、自由节奏转谱 |
| 原曲播放第一阶段 | 独立播放、循环、速度控制能力实测、手动锚点 | 频谱、复杂反复对应、联合音频运输 |

以上未确定项不会被擅自当作实施授权。每项待办都有最小交付、升级条件和验收边界，可以看完后只选一项开工。
