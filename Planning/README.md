## 现有工具与入口

| 工具 | 打开位置与主要用途 |
|---|---|
| 演奏编辑器 | 视图菜单；编辑力度、速度、踏板，与谱面选音同步 |
| 敲击测速 | 节拍器旁图标；测量速度，并可用于速度记号 |
| 和弦助手 | 视图 → 和弦助手；分析、谱面显示、人工范围与位置调整 |
| 编配检查 | 插件菜单 Arrangement Check；检查和声、对位及可弹性，保留范围并筛选结果 |
| 原曲参考 | 视图菜单；多轨、片段关联、一起播放，项目随谱保存 |
| 演奏表达 | 视图 → 演奏表达；导入或录制 MIDI、对应、试听及分范围采用力度和速度 |
| 分段试写 | 内置分段方案；插件菜单另保留完整谱副本。分别保存、切换与试听 |
| 频谱扒谱 | 演奏编辑器 → 扒谱；取音、试音、标注和输入 |
| 编配建议 | 视图 → 编配建议；AI局部写法、传统指法、换手、配音与对位 |
| 给定音高写节奏 | 演奏编辑器 → 写节奏；录制、修改草稿、试听和采用 |
| MIDI 人性化导出 | MIDI 导出选项；预览按键长度，结合踏板安排松手 |
| 音源与效果 | 视图菜单；选择VST／SF2、调整效果、预设与参数 |
| AI连接 | 视图菜单；配置随包MCP程序、检查连接与选择目标谱 |
