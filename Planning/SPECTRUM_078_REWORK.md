# 频谱显示范围与缩放检查

用户补充：原曲参考有关联选段时，频谱似乎只显示这一段，编辑器缩放后也没有一起改变。

## 按实际操作复查

1. 在独立八小节测试谱中，将录音8—12秒关联到第3—4小节。
2. 首次打开扒谱，检查当前音轨、时间方式和可见内容。
3. 显式选取关联片段，在频谱上缩放；检查卷帘、时间滚动条、频谱图和鼠标下的位置。
4. 在卷帘上缩放，检查同一位置的频谱是否一起变化。
5. 平移到关联外，再回到片段；切到整条录音，查看片段之外的内容。
6. 上下对照、叠加、悬浮、恢复停靠及切换工具页分别检查。标注与用户调整过的区域高度继续保留。

## 当前查到的处理

- 音轨首次出现时会自动选第一个关联，用户容易把片段显示误认为整条录音没有分析出来。
- 关联显示将分析范围限制在所选片段。需要把这个范围清楚写在时间方式中，并提供直接匹配显示范围的操作。
- 频谱自己的缩放处理直接改变编辑器比例，尚未更新编辑器时间滚动条；用实际滚轮检查缩放中心及可移动范围。
