# 演奏表达与播放的完整操作复查

## 本次要完成的操作

1. 在四小节钢琴谱选择范围，打开内置演奏表达，保留较小的表达区域。
2. 录入一段演奏，停止后直接看见具体音名、拍位、原／新力度以及使用入口。
3. 导入同段MIDI，在谱中效果与拟采用效果之间保持拍位切换，确认后几小节的音实际输出。
4. 到段尾停止，再播放、手动停止、继续切换；乐谱标签、选区与保存状态保持。
5. 在同一位置使用力度，核对音符保存值，一次撤销恢复。
6. 回查原曲参考的三种联合播放、连续停止和再次播放。

## 已检查到的覆盖范围

现有录制采用测试主要将工具悬浮后使用；播放测试使用单小节谱例。现增加内置小区域和四小节测试，确认实际结果是否可见、实际音符是否播放完整。用户谱与音频继续只读。
