# 0.61：指法与传统编配建议

操作见[使用说明](SUGGESTIONS_061_GUIDE.md)，计算方法与资料见[方法说明](SUGGESTIONS_METHOD.md)。版本定位：`personal-v0.61.0`。

## 本批完成

“编配建议”面板增加指法、换手、配音和对位选择，支持选段分析、取消、差异、试听、采用和保存另一种写法。个人跨度、风格和指法代价可调整并保存。

指法保留持续音的手指，合并同音多声部的物理按键；已有编号与分手参与安排。换手复用编配检查、MIDI松手处理中的按键判断。配音比较有限的八度变化，对位比较已有和弦音中的局部改音；新结果重新经过现有检查。

读取补充了选段前尚在保持的音。另修复自动分手被标成用户指定的问题，自动候选可以继续比较，手动说明优先保留。

实际窗口按“选段→分析→查看差异→采用→撤销”检查并保存截图。正式钢琴音源的人工听感和个人键盘手感需要结合使用时继续检查；本轮测试核对了音符、指法、演奏值和撤销结果。

音乐规则在可取消的工作线程运行，隐藏面板或换谱会结束本次任务；选段最多1024个音，指法每组保留32条状态，局部配音与对位试算分别有次数上限。准备最终候选时的乐谱克隆及排版仍在界面线程进行。
