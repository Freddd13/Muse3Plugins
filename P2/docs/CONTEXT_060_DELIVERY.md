# 0.60：当前谱读取与局部编配

完整操作见[使用说明](CONTEXT_060_GUIDE.md)。版本对应 `personal-v0.60.0`，MCP桥对应 `mcp-context-v2.2.0`。

## 已完成的操作

- 读取正在编辑的选段、完整声部、分数时值、演奏值、反复、分手和跨段连线；几何位置按需提供。同音不同声部保持独立。
- 编曲任务分别保留范围与要求。播放中可以查看同一版本已经读取的资料。
- 原生“编配建议”显示最多三版，提供差异定位、原／新试听、采用与保存分段写法。
- 音高、力度、指法、分手及整条声部的音符、休止和连音组通过原生编辑写入。采用前在副本检查，采用后读回比较，一次采用对应一次撤销。
- 用户说明、资料及采用记录随MSCZ保存。和弦助手的结果可供编配检查和AI读取。
- Windows安装补齐QtWebSockets；真实连接的重载、关闭和正常退出通过检查。
