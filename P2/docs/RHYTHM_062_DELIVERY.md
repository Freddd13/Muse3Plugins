# 0.62：给定音高写节奏

操作见[使用说明](RHYTHM_062_GUIDE.md)，本轮全部功能见[P2总览](P2_DELIVERY.md)。版本定位：`personal-v0.62.0`，宿主提交 `8e363ac92`。

## 实际操作

使用独立双谱表测试谱：C、D、E、F四组音，末音跨到下谱表，第一音带指法和调律，另有跨音圆滑线。

依次打开“写节奏”、送入四次带力度的MIDI输入、停止并保存录音、读取草稿、拖动末音、使用草稿、保存MSCZ、重新打开和撤销。音高顺序保持，起音按拖动改变；指法、调律、跨谱表位置和圆滑线随对应音移动。采用一次，撤销一次。

三连音例子核对了实际延音和渲染后的MIDI：拆分的E只有一次起音；再次把三连音改成普通节奏，原连音组正确替换。

草稿表格和音条经过真实窗口截图检查。原卷帘可以展开作对照，草稿与表格中间可拖动分隔条。普通编辑页保留原有布局，写节奏页按打开前的窗口大小安排空间。

## 耗时和保存

4000音谱例分63页读取，整次约86ms，单批最长约2.2ms。准备局部候选的同步克隆约146ms、检查约1ms、排版约43ms。读取分批让出界面，克隆与排版仍在界面线程进行。

八轨共同输出检查准备约72ms，有界音频缓冲约9MiB；128帧回调最大约2微秒，测试期间欠载为0。该混音处理与当前媒体模块相同，宿主另有播放会话归属标识。

录音默认保存在E盘。采用记录按文件摘要共用录音资料，草稿、来源和对应随谱保存；音符原力度继续使用已有的恢复方式。官谱与用户原谱保持原状。
